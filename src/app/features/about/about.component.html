We got tired of activewear that quit before we did.

ONE ELEMENT started in 2022 because good training gear was either too expensive, too basic, or built for someone else entirely. We figured if we had that problem, a lot of other people did too.

So we built the gear we wanted. Tested it. Broke it. Fixed it. Kept going until it held up the way it was supposed to. Two years later, that is still how every product gets made.
